# AI Agent 运行时加固更新说明

## 自动精简对话记忆

- 新安装默认开启自动精简，触发阈值由 75% 调整为 65%。
- 每次发送前会估算本轮上下文；达到阈值时，先将较早对话整理成摘要，再创建新会话发送。
- 工具轮发生机械裁剪时，会在消息流提示，并在下次发送前优先尝试语义压缩。
- 已保存过该设置的用户继续使用自己的开关和阈值；可在“设置 → AI 配置”中随时关闭或调整。

## 费用与月度预算

- 插件模型可同时声明 `prompt-price-per-m`、`completion-price-per-m` 和 `currency`；用户也可在“设置 → AI 配置”中按模型覆盖。
- 每次调用保存当时的单价快照，后续改价不会改写历史费用；缺少单价的记录显示为 `—`。
- 不同币种分别汇总，不做汇率换算。月度预算默认在达到 80% 时提醒，但不会阻断 AI 服务。
